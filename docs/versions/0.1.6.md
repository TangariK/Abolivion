## Resumo

- **Som:** menu ♪ (volume / ligar-desligar música e efeitos); SFX em UI, combate, buffs e amuletos
- Música de menu, run e **uma faixa por chefão** (Kurupi, Boitatá, Lobo Rei, Envenenador)
- Pause: música abafada; voltar ao menu para a música da run (sem overlap)
- Chefões novos nas Rodadas: **Lobo Rei** (30) e **Envenenador Master** (40)
- Zip: `abolivion-v0.1.6-gamejolt.zip`

---

## Áudio

1. Menu → botão **♪** (ao lado do perfil)
2. Preferências ficam só no save local (não sobrescrevem na nuvem)
3. Arquivos em `public/audio/` (CC0 via Freesound — ver `CREDITS.txt`)
4. Baixar/atualizar: `npm run audio:fetch` (requer `FREESOUND_API_KEY`)

---

## Chefões

- **Lobo Rei:** matilha, sangramento, agressivo com esquiva lateral
- **Envenenador Master:** poções com poça de veneno; maior alcance de arremesso
- Modo Livre (cenário custom): barra de HP do chefão; BGM do boss mais forte selecionado

---

## Correções nesta build

- Começar não trava após fechar dropdown de modo (blocker)
- Começar não fica morto após overlays HTML (Modo Livre / perfil) — `input` reativado
- Overlap menu + música da run ao voltar pelo pause
- Raio (Tempestade de Tupã): SFX só ao despertar o amuleto
- Latido ao pegar Dente de Guará
