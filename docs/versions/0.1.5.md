## Resumo

- **Online:** criar/buscar salas (públicas/privadas), link `?sala=CODIGO`, lobby sem tiro, countdown 5s
- Host autoritativo via Supabase Realtime; convidados com nomes de árvore
- Amuletos: Presas de Jurupari (L/R), Meia-Lua de Jaci, Misericórdia de Anhangá, Vigília de Iara
- Inimigos: Envenenador + 3 lobos do mal; HUD de **Veneno** / **Sangramento** no canto superior
- 5 conquistas online
- Zip: `abolivion-v0.1.5-gamejolt.zip`

---

## Online

1. Menu → Jogadores → **Online** (dropdown) → Começar
2. Criar sala (Infinito/Rodadas, pública ou privada + senha) ou Buscar / código
3. Lobby: andar livre, sem tiro; ao entrar o 2º → 5s → combate
4. Morte: espectar / esperar revive / **M** volta ao menu (encerra sala; o outro segue solo)
5. Escolha de buff/amuleto: luz dourada (invulnerável, sem tiro); mundo do aliado continua
6. Game Over online: só **Menu** (nova partida = criar/entrar em sala de novo)

Migração: `005_abolivion_rooms.sql` (`npm run db:migrate`).

## Correções nesta build

- Dropdown de jogadores; duas cabanas em 2P local/online
- Mira/mouse e tiro no online; sobrevivente herda controles no 2P local
- Nome do criador da sala no convidado; limpeza de `choiceProtected` / rearme de tiro
- “Tentar de novo” online não deixa o jogo preso no lobby sem sessão
