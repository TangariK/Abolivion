## Conta (Supabase)

- **Auth** (usuário / senha, e-mail opcional)
- Tabela `abolivion_profiles` com RLS (`auth.uid() = id`)
- Cliente: só `VITE_SUPABASE_URL` + `VITE_SUPABASE_ANON_KEY`
- Ao logar, progresso local é **mesclado** com a nuvem e salvo nos dois lados
- Migração: `npm run db:migrate` (`DATABASE_URL` no `.env`)

### Cadastro em duas etapas (e-mail opcional)

1. Conta nasce com `usuario@guest.abolivion.app` e entra na hora (`Confirm email` OFF).
2. E-mail real é vinculado pela Edge Function **`attach-email`** (Admin `generateLink` + API Brevo),
   sem SMTP do GoTrue — evita falha no endereço `@guest`.

Confirmação destrava recuperação de senha e novidades; nunca bloqueia o jogo.

No dashboard: `Confirm email` **OFF**, `Secure email change` **OFF**.  
Secrets da function: `BREVO_API_KEY`, `BREVO_SENDER` (`npm run functions:deploy`).  
No Brevo: desative **Authorised IPs** da API key.

### Perfil logado

- **Informações básicas** — usuário, e-mail (+/editar), tempo jogado, data de criação
- **Opções** — resetar senha, tag de nome in-game, novidades (se tiver e-mail)
- **Legado** — sobrevivência, sequência de abates, chefes, nível, kills, moedas, rodada, HP mínimo, precisão
- **Dev** (admin / local) — moedas, Visão de Dev, resetar progresso da conta

## Modo Livre

Antes da run: nível, buffs, amuletos, rodada ou tempo no Infinito, meta permanente, inimigos e chefões
(já desbloqueados; **Visão de Dev** libera tudo).

Não concede moedas, unlocks nem conquistas normais — só as exclusivas do modo
(`free_trial`, `triple_tyrants`, `naked_trial`; as duas últimas aguardam o 3º chefão).

## Setup local de conta

1. Copie `.env.example` → `.env`
2. Preencha `DATABASE_URL`, `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`
3. `npm run db:migrate`
4. Auth: **Confirm email** e **Secure email change** OFF; deploy `attach-email` (Brevo)
5. `npm run dev`

Detalhes de SMTP/Brevo: [README](../../README.md).
