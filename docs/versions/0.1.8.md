## Online (como funciona)

O **host** roda a simulação completa (spawn, AI, bosses). O **guest** é thin client: envia input (move/aim/firing) e aplica snapshots (~80 ms). Em 0.1.8 o snapshot inclui `bossId` / `isBoss` / HP / triggered e torretas leves; o guest chama `spawnBoss` corretamente.

Canal Realtime valida peer/role em hello, start, input, peerLeft, reviveAlly e snapshot. Salas `abolivion_rooms`: só o host atualiza/fecha (conta via RLS; host convidado via RPC).

---

## Save / sync

- `best_scores` + `almanac`: union / `Math.max` (não encolhem)
- `currency` + `meta_levels` + `resin`: **last-write-wins** por `updated_at` da nuvem vs save local
- Coluna `resin` em `abolivion_profiles` (migration `009`)
- Publishable key ainda permite spoof do próprio progresso — anti-cheat completo fica para depois
